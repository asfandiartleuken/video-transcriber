# Выпуск Video Transcriber для Windows и macOS

Подготовлена автоматическая сборка через GitHub Actions. Пользователю не требуется
устанавливать Python, FFmpeg или Whisper отдельно. Модели Whisper не входят в
установщик: при первом выборе модели нужен интернет; затем она хранится на
компьютере пользователя. Распознавание работает локально и не требует API-ключа.
Сборка с Torch может занимать сотни мегабайт или больше.

## Как получить установщики

1. Загрузите изменения проекта в свой GitHub-репозиторий. Не забудьте `assets/`:
   иконка сейчас является локальным файлом. Папки `venv/`, `tools/`, `build/` и
   `dist/` загружать не нужно. Существующие Linux-бинарники `tools/` сборка не использует.
2. На GitHub откройте **Actions → Desktop installers → Run workflow**.
3. Дождитесь успешного завершения всех трёх заданий. В разделе **Artifacts** будут:
   - Windows-x64: `Video-Transcriber-Windows-x64-Setup.exe`;
   - macOS-arm64: `Video-Transcriber-macOS-arm64.dmg` для Apple Silicon;
   - macOS-x64: `Video-Transcriber-macOS-x64.dmg` для Intel.
4. Скачайте артефакты и распакуйте ZIP-обёртку GitHub. Протестируйте установку,
   запуск, локальный файл, загрузку модели, отмену и YouTube на реальных компьютерах.
   Автоматическая проверка проверяет импорт Whisper, его данные, инструменты,
   Tcl и дочерний процесс; она не скачивает модель и не проверяет распознавание.
5. В **Releases → Draft a new release** создайте выпуск, например `v0.1.0`, и
   приложите `.exe`, оба `.dmg` и контрольные суммы. Публикуйте после проверки.
   Публичная ссылка на Release подходит для кнопки «Скачать».

Запуск по тегу `v...` тоже поддерживается. Сам workflow ничего не публикует и
не изменяет репозиторий. Для скачивания артефактов Actions требуется вход в GitHub;
для обычных пользователей используйте публичный Release. Исходники могут оставаться
в приватном репозитории, а установщики — в отдельном публичном репозитории.
Версия установщика пока `0.1.0` в `packaging/windows.iss`; перед новым выпуском
обновляйте её. Тег сам по себе версию установщика не меняет.

## Подписи и совместимость

Эти сборки пока без доверенной подписи издателя. Windows может показать SmartScreen,
а macOS Gatekeeper — заблокировать скачанное приложение. Для удобного публичного
распространения следующий этап — подпись Windows и Developer ID плюс notarization
на macOS. Сертификаты в проект не добавлены. Не предлагайте отключать защиту системы.
Сборки macOS создаются на macOS 15; поддержку более старых систем не обещаем.
Windows-сборка предназначена для x64; ARM и старые версии Windows требуют отдельной
проверки. YouTube зависит от изменений сайта и версии yt-dlp; поддержка всех ссылок
не гарантируется. Некоторые сценарии yt-dlp требуют дополнительного JS runtime.

## Локальная сборка на целевой системе

Нужен Python 3.11 с Tk. Создайте виртуальное окружение и установите
`pip install -r requirements-build.txt`. На Windows можно сначала установить CPU Torch:
`pip install torch --index-url https://download.pytorch.org/whl/cpu`.
На macOS установите `brew install ffmpeg`. Затем:

```sh
python scripts/prepare_tools.py
python scripts/build_desktop.py
```

На Windows с Inno Setup 6 выполните `ISCC packaging/windows.iss`.
Создание `.dmg` показано в `.github/workflows/desktop.yml`.
PyInstaller не собирает Windows/macOS установщики непосредственно на Linux.

## Сторонние компоненты

Сборка включает тексты лицензий Python-зависимостей и доступные лицензии инструментов
в `notices/` внутри приложения. Также сохраняются версии, источники FFmpeg и сведения
о Homebrew. FFmpeg содержит компоненты с GPL/LGPL; перед публичным выпуском нужно
проверить условия именно выбранных бинарников и обеспечить требуемые материалы
исходного кода и уведомления. Один файл со ссылкой не заменяет эти обязательства.
Настройки установлены на изменяемые FFmpeg URL и версии зависимостей с диапазонами;
точный список Python-пакетов сохраняется в `build-dependencies.txt`, но полностью
воспроизводимая сборка пока не обеспечена.
